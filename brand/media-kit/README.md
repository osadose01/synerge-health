## Brand Attribution & Editorial Rules

1. **Master Brand:** Always write **Synerge Health** on first reference (*"Synerge"* is acceptable only after first full mention in running prose). Never write *"Synerge Healthcare"*, *"SynergeHealth"* (outside URLs/emails), or *"Synergy Health"*.
2. **Venture Endorsement:** Attribute portfolio products strictly as **`from Synerge Health`** (lowercase `from` — e.g., *Metis POS, from Synerge Health*) or **`A Synerge Health venture`**. Never write *"Powered by Synerge Health"*.
3. **Editorial Tone & Spelling:** Use British English (`organisation`, `programme`, `enquiries`, `specialised`, `prioritise`, `anonymised`) and clear, clinical language. Avoid hype words (*"disruptive"*, *"world-class"*, *"cutting-edge"*, *"empower"*, *"leverage"*), exclamation marks, and unverified claims.
